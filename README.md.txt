## Deployment

### GitHub

1. Create a new repository.
2. Upload all project files.
3. Commit the changes.

### Netlify

1. Log in to Netlify.
2. Select **Add new site → Import from Git**.
3. Connect your GitHub repository.
4. Deploy the website.
